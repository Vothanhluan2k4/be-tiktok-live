# be-tiktok-live

TikTok Live Comment/Gift TTS Reader - Backend Node.js / Express Server

## System Features
- Real-time TikTok Live stream listener (`tiktok-live-connector`)
- Socket.IO realtime server broadcasting room events to OBS overlay clients
- Google TTS API speech URL generator & Vietnamese text template formatter
- Word filtering & gift minimum coin threshold rules
- Express REST API for streamer configuration & live connection management

## Setup & Run
```bash
npm install
npm run dev
```
